# Contributing

Contributions that improve clarity, reproducibility, accessibility, or the
responsible interpretation of the dataset are welcome.

## Local workflow

1. Fork or clone the repository.
2. Create a Python virtual environment.
3. Install `requirements.txt`.
4. Make a focused change.
5. Run `scripts/main.py` and inspect both the terminal output and generated chart.
6. Review `git diff` before committing.

Please keep beginner-facing examples small and explain unfamiliar concepts in
the README. Never contribute real patient data, credentials, API keys, or other
sensitive information.

## Reporting problems

When opening an issue, include:

- Your operating system
- Your Python version
- The exact command you ran
- The complete error message
- The smallest set of steps that reproduces the problem

Remove personal or sensitive information before posting logs or screenshots.
